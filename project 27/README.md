# Johnson Counter using Verilog HDL

## Overview

A Johnson Counter, also known as a Twisted Ring Counter, is a digital sequential circuit made using a shift register with the complemented output of the last flip-flop connected back to the input of the first flip-flop.

This project implements a 4-bit Johnson Counter using Verilog HDL.

The design includes:

- 4-bit Johnson Counter
- Synchronous operation using a clock
- Active-high reset
- Verilog RTL design
- Verilog testbench
- Simulation and waveform verification

## How a Johnson Counter Works

For an N-bit Johnson Counter, the counter has 2N unique states.

For a 4-bit Johnson Counter:

2 × 4 = 8 states

Starting from `0000`, the counter generates the following sequence:

| Clock | Q3 Q2 Q1 Q0 |
|------:|-------------|
| Reset | 0000 |
| 1 | 1000 |
| 2 | 1100 |
| 3 | 1110 |
| 4 | 1111 |
| 5 | 0111 |
| 6 | 0011 |
| 7 | 0001 |
| 8 | 0000 |

The sequence then repeats.

## Design

The next state is generated by shifting the current state to the right and feeding the complement of the last bit back into the first bit.
